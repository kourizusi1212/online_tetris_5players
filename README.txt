Online Tetris - 最大5人

必要:
- Node.js 18以上

起動:
1. このフォルダで `npm install`
2. `npm start`
3. ブラウザで http://localhost:3000 を開く

友達とオンラインで遊ぶ場合:
- このNode.jsサーバーをRender、Railway、Fly.io等のNode対応サービスへデプロイ
- 公開URLを友達に共有
- 「ルームを作成」で発行された6文字のコードを友達に共有し、「コードで参加」から入力

操作:
A = 右移動
D = 左移動
Z = 左回転
C = 右回転
W / Space = ハードドロップ
S = ソフトドロップ
Q = ホールド
P = 一時停止

最大5人。ライン消去時に他プレイヤーへおじゃまブロックを送ります。
