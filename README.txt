ONLINE TETRIS 5 - rebuilt

この版はオンライン対戦の部屋・開始・同期・勝敗・観戦・再戦部分を一から作り直しています。

残しているテトリス基本部分:
- 7種のブロック
- 左右移動
- Z/C/↑による回転
- S/↓ソフトドロップ
- W/Spaceハードドロップ
- Qホールド
- ゴーストブロック
- ライン消去演出

オンライン機能:
- 4桁ルームコード
- 最大5人
- 2人以上で部屋主がゲーム開始
- 相手盤面のリアルタイム表示
- 脱落後の観戦
- 最後の1人の勝利表示
- 再戦

Render:
Build Command: npm install
Start Command: npm start
Node.js version: 18+推奨
